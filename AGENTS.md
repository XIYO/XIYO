# Repository guide

This repository is the public GitHub profile for XIYO. Treat it as a curated entry point, not as a complete inventory of every repository.

## Rules

- Keep `README.md` English-first and maintain the matching Korean version in `README.ko.md`.
- Feature only public projects that have a usable entry point, an explicit maturity stage, and enough documentation for a first run.
- Link to each project's own README for installation details. Do not duplicate volatile versions, dependency lists, or implementation trees here.
- Do not expose a private repository, change repository visibility, or describe confidential work without an explicit review.
- Never publish credentials, personal source data, local absolute paths, or unredacted diagnostic output.
- Use the stage names `Preview`, `Experimental`, and `Archived` consistently. Add `Stable` only after the project documents a stable compatibility policy.
- Keep the profile concise. Repository-specific support, security, and contribution guidance belongs in the affected repository or the account-wide `.github` repository.

## Checks

- Confirm every linked project is public before adding it.
- Verify installation commands against the current CLI help and the target repository's public default branch.
- Review both language files in the same change.
